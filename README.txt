MOATAZ ASHRAF AWAD - REACT PORTFOLIO

Requirements: Node.js 20.19+ or 22.12+.

Run locally:
1. Open this folder in VS Code.
2. Open Terminal > New Terminal.
3. Run: npm install
4. Run: npm run dev
5. Open the local address printed by Vite.

Build for deployment: npm run build

Update projects in src/data/projects.js. Update text and translations in src/App.jsx.
Replace the portrait at public/assets/moataz-ashraf.jpg. Resume PDF is public/assets/Moataz_Ashraf_Awad_Frontend_Resume.pdf.
Use the palette icon in the header to switch between warm and light blue colors. Use the moon/sun icon to switch dark mode; both choices are saved in this browser. The language button switches English/Arabic, and the navigation collapses on smaller screens.
Icons are provided by react-icons and installed with npm install from package.json.
AOS scroll animations are configured in src/main.jsx; Lenis smooth scrolling wraps the app in src/App.jsx.
Only publish project details and results that are accurate.
